A database for a pharmacy network

The data model behind dispensing software shared by a group of pharmacies.

When
Harvard CS50 SQL, 2024
My role
Individual final project
Tools
SQL, SQLite

The problem

When patients use several branches of the same pharmacy group, each branch should see the same history: prescriptions, allergies and what was dispensed, by whom and when. The database also needs to track stock, expiry dates and suppliers.

The design

The schema links pharmacies, staff, patients, prescriptions, drugs and suppliers, with every dispensing event recorded against the staff member and patient involved. Financial accounting and compliance records were deliberately left out of scope.

The code is on GitHub, and the video overview explains the design.
